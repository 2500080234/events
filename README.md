# CampusConnect - College Event Management System

**Live demo:** https://2500080234.github.io/events/

A lightweight front-end web app for managing college events. Students browse and register for events; organisers add events and review registrations.

Built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Pages

- index.html - landing page with the next upcoming event
- user.html - student portal: search, filter and register
- admin.html - admin dashboard: add events, view registrants, delete events

## Run locally

Open index.html in Chrome or Edge, or use the VS Code Live Server extension.

## Data storage

Data is saved in the browser's localStorage, shared by all three pages. There is no backend or login yet.
